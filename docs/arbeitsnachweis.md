# Arbeitsnachweis für RelNotes

Pro Team und Modul einen kurzen Eintrag führen.

| Feld | Eintrag |
|---|---|
| Modul, Rollen, Live oder Fallback | |
| Issue und eigener Akzeptanzfall | |
| Basis-SHA, Arbeitsbranch, PR-Link | |
| Cursor-Lauf oder lokaler Ablauf, Aufwand und Stop-Grund | |
| Agent-Test und lokale Gegenprobe | |
| Actions-Lauf, Status, Head-SHA und Prüfschritt | |
| Review-Befund mit Dateistelle, Reproduktion und gewünschter Korrektur | |
| Korrektur-SHA, erneuter Check und Review | |
| Entscheidung, offene Punkte und nächster Verantwortlicher | |

Fehlende Evidenz als „ausstehend“ oder „lokal simuliert“ kennzeichnen. Keine
Secrets, privaten Laufprotokolle oder personenbezogenen Daten eintragen.
